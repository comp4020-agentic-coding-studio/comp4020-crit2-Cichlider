MyTimetable, actually explained

ANU's own timetabling pages are correct and thorough — they're also spread across a Getting Started guide, a Student User Guide PDF, an FAQ, and a separate "Timetable Viewer" that isn't the same tool. This page is an unofficial redesign: everything you need to get oriented, on one screen, before you go do the actual allocating on the real site.

What MyTimetable actually is

MyTimetable is ANU's self-allocation system: once your enrolment is in, it shows every teaching activity — lecture, tutorial, lab, seminar — attached to your enrolled courses, and lets you pick which tutorial or lab stream you attend where a course offers more than one. It runs clash detection while you choose, and it's separate from the read-only Class Timetable Web View, which shows the published grid but can't allocate you into anything.

  • Accessed via ANU single sign-on — no separate account to create.
  • Only shows activities for courses you're already enrolled in.
  • Lets you build a plan, swap allocations, and join a waitlist.

Where the real site struggles

None of this is a knock on the timetabling team — the system does a genuinely hard scheduling job. It's the orientation that's rough for a first-time user:

Two systems, one name
"Timetable" refers to both the read-only Web View and the allocation tool, and the official pages don't say which one you want until several paragraphs in.
The guide is a PDF
The clearest walkthrough of clash management, swaps, and waitlists lives in a downloadable Student User Guide — not searchable from the page you land on first.
No answer to "why can't I allocate yet"
A course appearing in the Web View but not open for allocation in MyTimetable is a common, confusing state that the front page doesn't warn you about before you go looking for it.
